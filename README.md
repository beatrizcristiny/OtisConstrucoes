# OtisConstruções

## Sobre o Projeto

O Site de maquinários tem como objetivo facilitar a locação de máquinas e equipamentos para empresas e pessoas que precisam utilizá-los por determinado período, sem a necessidade de comprá-los.

A plataforma permite que o usuário consulte os maquinários disponíveis, visualize informações como nome, categoria, descrição, preço e disponibilidade, e realize uma solicitação de aluguel. O sistema também pode permitir o cadastro e login de usuários, gerenciamento de reservas e acompanhamento dos aluguéis.

## Tecnologia Utilizada

- HTML
- CSS
- JavaScript
- PHP

## Descrição dos principais arquivos

### HTML

* **`HomePage.html`** — Página inicial do site, apresentando a empresa OtisConstruções e seus principais conteúdos.
* **`Equipamentos.html`** — Página responsável pela apresentação dos equipamentos disponíveis para locação.

### CSS

* **`HomePage.css`** — Responsável pela estilização da página inicial.
* **`Equipamento.css`** — Responsável pela estilização da página de equipamentos.

### JavaScript

* **`script.js`** — Contém os scripts responsáveis pelas interações e funcionalidades do site.
* **`login.js`** — Responsável pelas funcionalidades relacionadas ao login.

### PHP

* **Arquivos PHP** — Responsáveis pelo processamento das informações enviadas pelo site e pela comunicação com o banco de dados.

### Imagens

* **`andaime.jpg`**, **`betoneira.jpg`**, **`compactador.jpg`**, **`gerador.jpg`**, **`martelete.jpg`** — Imagens utilizadas para representar os equipamentos disponíveis.
* **`logootis.png`** e **`make-logo-black.png`** — Logos utilizados na identidade visual do site.
* **`fundo.jpg`**, **`fundopt2.jpg`**, **`obras.jpg`** e **`pessoas.jpg`** — Imagens utilizadas como elementos visuais e fundos das páginas.
